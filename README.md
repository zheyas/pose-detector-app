# Приложение для распознавания частей тела

Десктопное приложение на Python с графическим интерфейсом, которое использует **MediaPipe** и **OpenCV** для распознавания позы человека на изображениях или через веб-камеру. Программа позволяет аннотировать изображение, проверять видимость лица и генерировать отчёт в формате `.docx`.

## 📦 Функциональность

- 📷 Загрузка изображения с компьютера и определение позы.
- 🧍 Отображение аннотированных точек тела на изображении.
- ✅ Проверка, полностью ли видно лицо.
- 📄 Автоматическое создание отчёта `results.docx` с изображением и списком видимых частей тела.
- 🔍 Возможность использовать веб-камеру (опционально, отключено по умолчанию).

## 🛠️ Установка

### 1. Клонируйте репозиторий

```
git clone https://github.com/zheyas/pose-detector-app.git
cd pose-detector-app
```
### 2. Создайте виртуальное окружение (рекомендуется)
```
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
```
### 3. Установите зависимости
```
pip install -r requirements.txt
```

## 🚀 Запуск
```python main.py```

## 📁 Структура проекта
```
.
```

## 📄 Отчёт
После обработки изображения или фото с камеры:
- Генерируется файл results.docx
- Включает изображение с аннотациями и список видимых частей тела

## 💡 Примечания
- Программа ориентирована на распознавание человека, находящегося полностью в кадре.
- Минимальная видимость лица проверяется по координатам носа, ушей и глаз.
- Используется модель MediaPipe Pose с параметром static_image_mode=True.
